# 💌 Postcardly

## Vision

A beautiful platform where people can create, send, and preserve heartfelt digital postcards.

## MVP Features
- User Authentication
- Create Letter
- Choose Template
- Preview Letter
- Send via Email
- Dashboard
- View Received Letter

## Future Features
- Reply to Letters
- Animated Envelopes
- Stickers
- Scrapbook Editor
- Music
- Schedule Delivery
- Collaborative Letters
- Memory Vault
